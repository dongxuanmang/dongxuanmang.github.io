学习路径

这是我的学习路径总览——每个主题域按「基础 → 进阶 → 实战」渐进展开，学完并写成文章的节点会变成链接。这个页面就是我的学习 wiki，随进度持续更新。

状态标记：✅ 已完成 ｜ 🔄 进行中 ｜ 📋 计划中

🤖 AI 基础知识

目标：用大白话讲清楚 AI 的核心概念，给转型路上的同学铺路。

L1 概念层

  • 📋 大模型是怎么工作的：token、上下文窗口、温度
  • 📋 训练 vs 推理 vs 微调：一张图分清
  • 📋 Prompt 不是玄学：模型为什么会「一本正经地胡说八道」

L2 原理层

  • 📋 Transformer 最小可读版：注意力机制到底在算什么
  • 📋 Embedding：把万物变成向量的魔法
  • 📋 RAG 为什么是企业的第一站：检索增强的工程本质

L3 动手层

  • 📋 用 API 搭一个最小可用的 AI 应用
  • 📋 本地跑一个开源模型：从 Ollama 开始

🛠️ AI Agent 开发

目标：从传统后端转型 AI agent 开发，最终能设计并实现生产级 agent。

L1 入门

  • 🔄 提示工程实战：结构化输出、few-shot、思维链
  • 📋 Function Calling / Tool Use：模型怎么「动手」

L2 框架与源码

  • 📋 主流 agent 框架横评：带着「我要什么」去看
  • 📋 拆一个 agent 框架的源码：规划、工具调用、记忆是怎么接起来的
  • 📋 多智能体协作：任务怎么拆、消息怎么传

L3 实战

  • 📋 用 agent 重构我的工作流：一次真实的工程化记录
  • 📋 生产级 agent 的三件事：稳定、可观测、可回滚

🎬 AI 短视频赛道

目标：跑通 AI 内容生产流水线，形成对赛道机会的独立判断。

L1 工具层

  • 📋 主流 AI 视频工具盘点：文案、数字人、剪辑、配音
  • 📋 一条视频的最小闭环：从选题到发布的全自动尝试

L2 流水线层

  • 📋 内容流水线设计：选题 → 脚本 → 素材 → 成片的自动化
  • 📋 账号实操数据复盘：什么内容能跑起来

L3 赛道层

  • 📋 赛道观察：玩家、商业模式、护城河
  • 📋 我的判断与押注

💰 投资相关

目标：建立自己的投资认知框架，用文字倒逼思考。

L1 认知层

  • 📋 为什么大多数人跑不赢指数：行为金融学入门
  • 📋 我的投资原则清单

L2 方法论层

  • 📋 信息源管理：我怎么筛选投资信息
  • 📋 复盘模板：每一笔决策背后的假设

L3 实践层

  • 📋 实践记录与年度复盘

🧱 后端工程（已通关区）

这是我的老本行，基础已经打完，此区域作为归档，相关新知会写成文章。

  • ✅ 高并发服务设计与稳定性保障（大厂实战沉淀）
  • ✅ Hive 引擎与大数据作业链路（职业生涯起点）
  • 🔄 AI 时代的后端新题：agent 应用的后端架构

使用说明（给自己）

  1. 每个节点从 📋 开始，动手了改 🔄，写成文章后改 ✅ 并加文章链接
  2. 节点不是考试大纲，是「想搞懂什么」的清单，顺序可跳
  3. 每季度回看一次：删掉不再想学的，补上新冒出来的
  4. 写文章时从这里选题，写完回填链接——这就是博客和学习的飞轮
