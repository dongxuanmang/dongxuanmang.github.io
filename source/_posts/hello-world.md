欢迎来到我的博客。

这是本站的第一篇文章。博客基于 Hexo 搭建，托管在 GitHub Pages 上，主要用于记录技术笔记、问题排查过程和日常思考。

## 这个博客会写什么

- 技术笔记：开发中踩过的坑、解决方案、工具使用技巧
- 读书与思考：看到的好文章、好书的一些想法
- 生活记录：偶尔写点工作之外的事

## 博客是怎么搭起来的

如果你也想搭一个一样的博客，核心只需要三步：

1. 在 GitHub 创建一个名为 `<用户名>.github.io` 的公开仓库
2. 本地安装 Hexo：`npm install -g hexo-cli`，然后 `hexo init` 初始化站点
3. `hexo clean && hexo generate && hexo deploy`，生成静态文件并推送到仓库的 `gh-pages` 分支，GitHub Pages 自动发布

源文件和生成的页面分别放在同一个仓库的 `main` 和 `gh-pages` 两个分支里，方便版本管理。
