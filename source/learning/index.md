## 🤖 AI 基础知识

目标：用大白话讲清楚 AI 的核心概念，给转型路上的同学铺路。

### L1 概念层

- 📋 大模型是怎么工作的：token、上下文窗口、温度
- 📋 训练 vs 推理 vs 微调：一张图分清
- 📋 Prompt 不是玄学：模型为什么会「一本正经地胡说八道」

### L2 原理层

- 📋 Transformer 最小可读版：注意力机制到底在算什么
- 📋 Embedding：把万物变成向量的魔法
- 📋 RAG 为什么是企业的第一站：检索增强的工程本质

### L3 动手层

- 📋 用 API 搭一个最小可用的 AI 应用
- 📋 本地跑一个开源模型：从 Ollama 开始

## 🛠️ AI Agent 开发

目标：从传统后端转型 AI agent 开发，最终能设计并实现生产级 agent。

### L1 入门

- 🔄 提示工程实战：结构化输出、few-shot、思维链
- 📋 Function Calling / Tool Use：模型怎么「动手」

### L2 框架与源码

- 📋 主流 agent 框架横评：带着「我要什么」去看
- 📋 拆一个 agent 框架的源码：规划、工具调用、记忆是怎么接起来的
- 📋 多智能体协作：任务怎么拆、消息怎么传

### L3 实战

- 📋 用 agent 重构我的工作流：一次真实的工程化记录
- 📋 生产级 agent 的三件事：稳定、可观测、可回滚
